# Requirements
FR-01 ingest approved telemetry fields.
FR-02 validate schema and ranges.
FR-03 store approved observations.
FR-04 execute a rule-based anomaly baseline.
FR-05 compare an Isolation Forest detector.
FR-06 produce technician-readable anomaly evidence.
FR-07 record configuration/model versions and evaluation results.
FR-08 preserve human decision authority; no autonomous hardware control.

NFRs: performance, usability, reliability, scalability, security, privacy, reproducibility, and maintainability.
